## 👋 Hi, I'm Maryam

I'm a **Forward Deployed Engineer** and **AI Agent Engineer** who ships end-to-end products — from multi-agent AI systems and RAG-powered backends to polished, responsive front-ends.

I'm **Anthropic-certified** in Claude Code and the **Model Context Protocol (MCP)** — the same toolkit I use daily to design reliable, production-grade AI workflows.

My sweet spot is the messy middle: **taking an ambiguous problem, translating it into a working architecture, and delivering something people actually use.** I pair strong full-stack engineering with a designer's eye, so the outcome is functional *and* beautiful.

> *"Ship it, learn from it, make it better."*
